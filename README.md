# Darkys-Launcher

# TR

Minecraft sürümlerini ve modpack’lerini yönetmek için geliştirilen, Windows odaklı bir launcher.

> Darkys Launcher, Mojang veya Microsoft tarafından geliştirilmemiş ya da onaylanmamıştır. Minecraft’ın resmî dosyalarını kullanır. Oyuna erişim için geçerli bir Minecraft hesabı gerekebilir; çevrimdışı profil desteği, hesabın sahipliğini veya oyuna erişim hakkını sağlamaz.

## Özellikler

- Mojang sürüm listesinden Minecraft sürümlerini görüntüleme
- Fabric, Forge ve NeoForge modpack profilleri oluşturma
- Her modpack için ayrı oyun klasörü ve mod yönetimi
- Modrinth `.mrpack` içe ve dışa aktarma
- Modpack arşivlerini içe ve dışa aktarma
- Modrinth ve CurseForge içeriklerini arama ve indirme
- Oyun logları ve çökme raporları için yerel analiz
- CurseForge API bağlantı testi
- Windows için kurulum sihirbazı (NSIS), masaüstü ve Başlat menüsü kısayolları

CurseForge özellikleri için geçerli bir API anahtarı gerekebilir.

## Gereksinimler

- Windows 10 veya üzeri
- Geliştirme ve kaynak koddan çalıştırma için Node.js
- Minecraft sürümüne ve mod yükleyicisine uygun Java kurulumu

## Kullanım

1. Launcher’ı aç.
2. Yeni bir modpack profili oluştur.
3. Minecraft sürümünü, mod yükleyicisini ve yükleyici sürümünü seç.
4. Modpack içinden modlarını yönet.
5. Profili seçip oyunu başlat.

# EN

A Windows-focused launcher developed for managing Minecraft versions and modpacks.

> Darkys Launcher is not developed or endorsed by Mojang or Microsoft. It utilizes official Minecraft files. A valid Minecraft account may be required to access the game; support for offline profiles does not grant ownership of an account or the right to access the game.

## Features

- View Minecraft versions from the official Mojang version list
- Create modpack profiles using Fabric, Forge, or NeoForge
- Separate game directories and mod management for each modpack
- Import and export Modrinth `.mrpack` files
- Import and export modpack archives
- Search for and download content from Modrinth and CurseForge
- Local analysis of game logs and crash reports
- CurseForge API connectivity testing
- Windows installer wizard (NSIS) with Desktop and Start Menu shortcuts

A valid API key may be required for CurseForge-related features.

## Requirements

- Windows 10 or later
- Node.js (for development and running from source code)
- A Java installation compatible with the specific Minecraft version and mod loader

## Usage

1. Open the launcher.
2. Create a new modpack profile.
3. Select the Minecraft version, mod loader, and loader version.
4. Manage your mods within the modpack.
5. Select the profile and launch the game.
